# 💼 Portfolio — Raoul

Portfolio personnel développé dans le cadre de ma formation **Développeur Web et Web Mobile (DWWM)** à l’AFPA.
Ce site a pour objectif de présenter mon profil, mes compétences et mes projets en cours ou terminés.

## 📋 Description

Ce portfolio regroupe :

* une présentation de mon parcours
* mes compétences techniques
* mes projets
* les moyens de me contacter
* un design simple et efficace
* la mise en valeur des projets
